# RevoU To-Do List

## Deskripsi
RevoU To-Do List adalah aplikasi web interaktif untuk mengelola tugas sehari-hari.  
Dibuat dengan **HTML, CSS, JavaScript**, serta animasi **Typed.js** dan **AOS.js** untuk pengalaman yang lebih dinamis dan responsif.

Fitur utama:
- Menambahkan tugas dengan tanggal.
- Menandai tugas selesai atau belum selesai.
- Menghapus tugas individu atau semua tugas sekaligus dengan konfirmasi.
- Notifikasi toast untuk setiap aksi.
- Animasi teks dinamis di header dengan Typed.js.
- Efek animasi elemen saat scroll dengan AOS.js.
- Responsive untuk desktop dan mobile.

---

## Cara Menggunakan
1. **Menambahkan Tugas**  
   - Isi form judul tugas dan tanggal.  
   - Klik tombol **➕ Tambah**.  
   - Jika form kosong → muncul notifikasi untuk mengisi form.  

2. **Menandai Tugas Selesai**  
   - Klik tombol **Selesai / Belum** pada tugas untuk menandai.  
   - Tugas selesai akan dicoret dan progress bar diperbarui.  

3. **Menghapus Tugas**  
   - Klik tombol **Hapus** untuk menghapus tugas tertentu.  

4. **Menghapus Semua Tugas**  
   - Klik tombol **🗑️ Hapus Semua**.  
   - Akan muncul konfirmasi **Ya / Tidak**.  
   - Pilih **Ya** → semua tugas dihapus.  
   - Pilih **Tidak** → aksi dibatalkan.  

5. **Mencari Tugas**  
   - Gunakan kolom **Cari tugas…** untuk memfilter tugas berdasarkan kata kunci.

---

# Menggunakan
- **HTML5 & CSS3** – Struktur & tampilan.
- **JavaScript (Vanilla)** – Logika aplikasi.
- **Typed.js** – Animasi teks header.
- **AOS.js** – Animasi elemen saat scroll.
- **LocalStorage** – Menyimpan tugas agar tetap ada saat reload.
